Get started

Get started

Two units, one switch each, no network.

Switch on and choose a language

  1. Switch each unit on with the rocker switch.
  2. Choose your language on the start screen. Each unit keeps its own language, so the doctor and the patient can read different ones.
  3. The Doctor Station opens its main menu. The Bed Unit waits for questions.

Doctor Station

Pick a bed and send a question.

DigitsEnter numbers
STOPSends or confirms (or 5 in lists)
STARTGoes back. Hold for 1 second to return to the main menu.
F1 to F4Function keys

Bed Unit

Answer with the digits.

1YES or OK
2NO
9Please repeat
7Ask for help, then the request number, then #
